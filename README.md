# mflabs

Tools built by [mfBRAT](https://mfbrat.com).

---

## Tools

### [claude-monitor](./claude-monitor)
Mac menu bar app that monitors Claude Pro usage in real time. Shows 5-hour and 7-day usage windows with a dark MFbrat-themed popover. Auto-starts on login, zero config after first setup.

**Stack:** Python, PyObjC, WKWebView

---

### [mf-monitor-safu](./mf-monitor-safu)
BTC wallet monitor. Watches addresses and alerts on activity.

**Stack:** Python

---

### [opensea-monitor](./opensea-monitor)
Monitors OpenSea listings and activity.

**Stack:** Node.js

---

### [pfp-scale-bot](./pfp-scale-bot)
PFP scaling bot.

**Stack:** Node.js

---

### [web-golf](./web-golf)
Turns any webpage into a top-down mini-golf course. Headings become walls, text becomes rough, images become bumpers, and the page's CTA buttons become the holes. Runs as a bookmarklet.

**Stack:** Vanilla JS, Canvas
